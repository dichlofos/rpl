# LRPL photo probe

Экспериментальный CLI для первого этапа фото-MVP. Он рекурсивно сканирует
JPEG-каталог, включая JPEG/MPO с нескольких современных телефонов, читает
базовый EXIF, считает SHA-256, 256-битный difference hash, 64-битный DCT pHash
и оценку резкости, предлагает поправки времени по GPX и формирует временные
эпизоды с вложенными стопками похожих кадров.

Установите зависимости для фотопрототипа:

```bash
python -m pip install -e '.[photos]'
```

Запуск:

```bash
python -m lrpl /path/to/photos \
  --gpx /path/to/day-01.gpx \
  --gpx /path/to/day-02.gpx
```

Полный машиночитаемый результат:

```bash
python -m lrpl /path/to/photos --gpx /path/to/track.gpx --json
```

Поправка времени определяется соглашением:

```text
нормализованное время = исходное время EXIF + поправка
```

Например, для камеры, показывающей местное `12:00`, и точки трека `09:00Z`
поправка равна `-03:00`.

По умолчанию соседние кадры одной камеры с разрывом не более 10 секунд входят
в один временной эпизод. Внутри него точные и визуально близкие фотографии
собираются в более узкие стопки. Порогами можно управлять параметрами
`--episode-gap-seconds`, `--difference-hash-distance` и
`--perceptual-hash-distance`.

Текущие отпечатки, оценка резкости и ранжирование поправок — исходные алгоритмы
для проверки на реальных данных, а не окончательные продуктовые пороги. EXIF
исходных файлов не изменяется.
